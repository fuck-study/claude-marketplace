# fuck-study Claude Marketplace

Long 项目的 Claude Code 插件 Marketplace。

## 添加 Marketplace

```bash
claude plugin marketplace add fuck-study/claude-marketplace
```

## 安装插件

```bash
claude plugin install long-skills
```

## 包含的插件

| 插件 | 说明 |
|------|------|
| `long-skills` | deploy.yaml 描述更新、API 安全分析 |
